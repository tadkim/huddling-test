# 내 자리 만들기

이 폴더를 `features/<내 GitHub 아이디>/`로 복사하면 내 자리예요. `me.json`이 merge되면 작업실에 내 캐릭터가 앉아요.

## 레벨 1 · 5분: 앉기

`me.json`만 채우고 PR을 올려요.

| 칸 | 넣는 값 |
|---|---|
| `name` · `role` | 보일 이름, 역할 |
| `color` | 옷 색 1~8 (`styles/tokens.css`의 `--pixel-color-N`) |
| `hair` · `skin` | 머리 1~4, 피부 1~3 |
| `status` | `작업 중` · `막힘` · `완료` · `쉬는 중` |
| `says` | 말풍선 한 줄 |
| `tools` | 오늘 쓴 도구 |

Claude에게: `me.json에 내 이름 ○○, 옷 색 3번, 말풍선 "○○"로 넣어줘`

## 레벨 2: 내 캐릭터 직접 그리기 · 내 페이지

- `sprite`: 16줄 × 16칸 글자 그림. `.` 투명 · `k` 선 · `h` 머리 · `s` 피부 · `c` 옷 · `w` 흰색. 크기가 틀리면 기본 캐릭터로 보여요.
  - Claude에게: `안경 쓰고 모자 쓴 내 캐릭터를 me.json sprite 규칙대로 16×16으로 그려줘`
  - Figma에서 16×16으로 그린 뒤 `이 그림을 sprite 글자로 바꿔줘`도 돼요
- `index.html`: 작업실에서 내 자리를 누르면 열리는 내 페이지. 자유롭게 꾸며요.

## 레벨 3: 동료와 외부 도구

- `agents`: 내가 만든 에이전트를 `[{ "name": "리뷰봇", "says": "한 줄" }]`로 넣으면 캐릭터 곁에 작은 로봇이 붙어요.
- Higgsfield · 영상 · uibowl 같은 도구로 만든 결과물을 내 페이지에 붙여요. 파일은 이 폴더 안에 둬요.
- 막히면 `status`를 `막힘`으로 바꾸고 `says`에 막힌 내용을 적어 PR → 작업실에서 말풍선이 흔들려요.

## 지킬 것

- 이 폴더 밖은 고치지 않아요.
- 색은 `var(--…)`나 팔레트 번호만 써요.
